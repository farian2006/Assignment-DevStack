Project Name: DevStack 

Description : DevStack is a web application that allows user to explore different technologies and create their own personalized stack.User can  Browse, Add and Remove technologioes as per their choice.


Technologies Used :
1. React.js
2. TypeScript
3. Tailwind CSS
4. React Icons
5. JavaScript
6. HTML
7. JSON
8. Vite
9. DaisyUI
10. React-Toastify

Features:

1. Technology Exploration
Users can explore different technology categories such as Frontend, Backend, Database, Language, Styling, DevOps, and Tools.

2.  Personal Development Stack
Users can add technologies to Your Stack and build their own personalized development stack. The same technology cannot be added more than once

3. Interactive UI
User Can Browse,Add and Remove The Technology Using InterActive Buttons
